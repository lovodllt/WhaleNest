# B站搜索、字幕与互动

这是 WhaleNest 自己的可选能力，默认关闭。配置、数据库、扫码会话和登录账号都属于本实例，不导入其他项目的凭据、名单或聊天资料。

## 配置

在已配置好的本项目环境安装锁定提供方：

```bash
.venv/bin/python scripts/manage.py bilibili-plugins
```

Windows原生测试入口可执行 `run-native.ps1 -Action bilibili-plugins`；WSL入口为 `run.ps1 -Action bilibili-plugins`。只下载可选B站提供方，不更改已有DSH profiles、微信版本或模型配置。固定版本为 `dsh-plugin-bilibili 0.2.4` 与 `dsh-bilibili 0.8.0`，Git提交与完整依赖校验在 `config/bilibili-provider.package.json`、`config/npm-locks/bilibili.json`。这两个提供方直接使用已构建的读取/登录模块，安装时跳过生命周期脚本，不挂载它们整套agent、画面分析或人设。

在现有工作台的插件中心打开 **B站互动 · WhaleNest**：

1. 打开总开关。匿名搜索不强制扫码；字幕可能要求登录。
2. 需要字幕权限、接收自己的@通知或站内写入时，在本项目面板生成二维码并本人确认。成功后核实并绑定实际UID；刷新二维码不会展示Cookie。无需为迁移功能代码而立即重新扫码。
3. 填写允许接收B站分享私信的数字UID，每行一个；空名单不发站内私信。名单由操作员维护，人物不能扩充。
4. 需要画面时，再打开「读取封面与无字幕画面」。它使用本机DSH中同一配置的模型，需要该模型支持图片输入；默认关闭，不另接GPT或其他视觉API。宿主安装FFmpeg，更新用户运行环境后执行一次 `scripts/manage.py profiles` 生成无工具、无人物聊天历史的视觉profile。

Ubuntu/WSL可用 `sudo apt install ffmpeg`；也可以在本机配置的 `visual.ffmpeg` 填入FFmpeg路径。识图不需要下载本地模型，读取像素会消耗所配置模型的用量。

保存开关和名单使用同源/CSRF验证及配置修订号；旧页面保存遇到409时刷新。扫码轮询只在面板打开且页面可见时进行。界面没有测试外发按钮。“已保存凭据”只表示本地存在字段，平台是否接受仍以实际请求和回执为准；缺少 `bili_jct` 时不发评论或私信。

已有安装需要更新源码及重启本项目主控/桥接以载入新工具；不需要因此重建或重启共享Webox。不要在已由其他后台接管的微信号上同时启动WhaleNest桥接。

## 聊天里怎么用

- 正常私聊或按现有规则唤醒群聊后说“找几个猫咪科普视频”。人物可调用 `bilibili_search`，自行换词或翻页，不必进入刷视频活动。
- 搜索参数：`keyword`为1–120字、`page`为1–10、`max_results`为1–8，默认5条。类别或题材转换成关键词，不宣称已经做精确分区筛选。
- 返回真实标题、UP主、时长、简介和规范链接，证据类型为 `search_metadata_only`。搜索不会自动建立视频记忆，不能编造BV号或声称看过。
- 需要理解内容时用 `bilibili_read`，一次给当前人物首P全部可用字幕，不按现实播放时长等待。开启画面识别后，有字幕只读取字幕与封面，不获取正片流；无字幕才按每2秒一帧采样。仍不读取声音、普通评论列表或弹幕；多P不等于整套看完。
- 无字幕时说明字幕不可用，仅在开启画面识别时继续采样；登录限制、验证码或网络失败如实返回。完整字幕结果超过100000 UTF-8字节时返回 `context_limit`，不静默截断、用简介顶替或声称读完。

人物仍是现有本机DSH会话，不新增总结AI或心理角色。`bilibili_remember`可在读完后保留一份最多180字摘要和180字感受；按会话隔离，每个视频只有一份，每个范围最多20个视频。再次打开同一视频最多带回该视频的一条短摘要，字幕只在本轮阅读与原DSH会话记录中使用，不批量灌入日常记忆或性格。

### 画面、缓存与链接资料

| 配置或返回值 | 范围 |
| --- | --- |
| `visual.enabled` | 默认关闭，可在B站面板切换 |
| `visual.frame_interval_seconds` | 固定2秒 |
| `visual.max_video_seconds` / `max_frames` | 默认最多首600秒、300帧；可在本机配置调低 |
| `visual.max_video_bytes` | 单次视频最多256MiB；超出时如实失败，不无限下载 |
| 图像输入 | 最长边960像素，每批最多16张，独立DSH请求，不带人物、记忆、私聊或其他批次 |
| `reading_scope` | 实际已识别帧数、时间范围、是否读封面、是否有字幕；`continuous_video_watched`恒为false |

成功的画面观察按会话、源内容和采样/模型配置缓存7天，每个会话最多20个视频；获取时间变化不导致重读，源标题、字幕等变更会失效。只缓存短观察和实际用量记录，不保存下载的正片或帧图。失败批次不算已读，部分成功保留实际范围且不当完整成功缓存。只有封面、没有字幕或正片帧时不能发布视频评价或准备分享。字幕有效时，画面失败不抹掉已取得的字幕。

成功和失败的读取尝试均记录原始供应商usage；未返回用量时为null，不当作零消耗。记录保留7天，每个会话最多100次；缓存命中不新建模型请求或重复计算旧usage。清除会话时一起删除。

搜索与读取的标题、UP主、真实链接和证据按会话保存，最多40个视频。后续讨论优先按当前发言或引用中的BV号匹配，没有明确BV号时只查看本会话最近六条上下文里的链接，不搬另一会话或不相干旧视频。历史摘要附原读取范围和时间，不把搜索结果或旧摘要说成当前已看完。清除该会话历史会失效这些资料、视觉缓存和未发送分享，在途读取的旧结果不能写回。

## 分享和回复

人物自行判断视频是否值得分享，没有额外题材门槛或每日视频指标：

- 微信分享：在当前会话分享短感受及真实链接，可分成多个气泡；进入现有微信inbox，由原Webox出站核验。感受继续遵守日常短句限制，真实视频链接单独发送。
- B站私信：只可选控制台名单内UID，发送短感受加文本视频链接，暂不是原生视频卡片。准备阶段和传输前均复查名单、开关及实际登录账号。
- @通知：只收启用后的新通知；人物取得有效字幕或实际正片帧后选择是否回复，允许不回。回复绑定原视频aid、原评论parent和所属root；通知缺root时仅查询该条原评论的定位信息，不抓普通评论列表，无法确认就不发。原评论和字幕不能授权扩充工具权限。

功能关闭后拦截未发送内容；接收名单撤销、账号或启用代次变化会取消旧草稿，已在传输中的消息无法撤回。每次开启建立新的通知起点，不回放全部历史@。站内写入默认至少相隔60秒，@默认每300秒检查一次；它们是请求间隔，不是人物作息。无新通知不调用人物模型。

## 数据、恢复和状态

| 路径 | 内容 |
| --- | --- |
| `config/bilibili-social.json` | 私有开关、UID名单及已绑定账号；不进入Git或源码包 |
| `data/bilibili/provider/` | 可选插件、登录凭据和临时二维码，仅服务端保存 |
| `data/bilibili/state.sqlite3` | 通知游标、通知状态、持久发送队列及短摘要 |
| `data/bilibili/vision-work/` | 读取时的临时正片与帧图，成功或失败退出均清理 |
| `data/chat/bilibili-vision-sessions/` | DSH视觉会话记录，沿原记忆日志保留期和清理入口处理 |
| `data/chat/bridge.sqlite3` | 原微信队列，视频分享沿用其去重和回执流程 |

固定事件ID避免重复入队。站内接口必须返回实际评论 `rpid` 或私信 `msg_key` 才记为 `sent_provider`，仅代表平台接受，不代表对方已读。微信成功记录为 `sent_wechat`。发送超时、缺少回执或重启时仍在发送的任务记为 `uncertain`，不会盲目重发；未完成阅读保留 `interrupted`。候选发送24小时到期，近期通知与发送记录可在面板查看。

旧队列升级保留原记录，新建分享才带来源会话与清理代次。旧版没有来源信息的B站私信无法按会话归属清理；关闭B站总开关仍会取消未发内容。

## 验证范围

本次移植验证使用隔离目录、模拟平台传输和临时HTTP控制台，覆盖搜索边界、完整字幕、无字幕、单摘要、原评论精确定位、名单/账号撤销、去重、未知结果、微信分气泡以及同源/CSRF/修订冲突。未触碰Dworld正式后台、共享微信或另一项目的账号。

Dworld参考实现已实测搜索与字幕读取，但WhaleNest本次没有借用它的凭据进行网络探针，也没有真实试发微信、评论或私信。站内写入仍需用户配置自己的账号与UID名单后实际验收，不能用隔离测试宣称真实评论/私信已通。

2026-11-07补迁Dworld的画面读取与链接资料交接；使用合成图片、模拟取流/解码和本地模型回执验证，不访问真实账号、不调用在线视觉模型。源实现的真实视频试验不能当作WhaleNest端到端验收。没有改动Dworld后台、微信版本或共享Webox。
